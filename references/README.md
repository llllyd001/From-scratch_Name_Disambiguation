# Research References

1. Chen, B., Zhang, J., Zhang, F., Han, T., Cheng, Y., Li, X., Dong, Y., Tang,
   J. **Web-Scale Academic Name Disambiguation: The WhoIsWho Benchmark,
   Leaderboard, and Toolkit.** Proceedings of the 29th ACM SIGKDD Conference on
   Knowledge Discovery and Data Mining, 2023, 3817-3828.
2. Cheng, Y., Chen, B., Zhang, F., Tang, J. **BOND: Bootstrapping From-Scratch
   Name Disambiguation with Multi-task Promoting.** Proceedings of the ACM Web
   Conference 2024, 2024, 4216-4226.
3. Ye, F., Xia, Z., Ling, Z., Wu, L. **Multi-view Contrastive and
   Cluster-Guided Learning for Author Name Disambiguation.** Expert Systems with
   Applications, 2025, 289:128324. DOI: 10.1016/j.eswa.2025.128324.
